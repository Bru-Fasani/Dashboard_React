<div align="center"> <h1> Thunder Motorsport Dashboard React ⚡ </h1> </div>

## Simples dashboard para o gerenciamento de uma equipe de arrancada fictícia, a Thunder Motorsport.

Exibir informações como:
- Estatísticas da equipe 
- Número de vitórias 
- Melhor tempo 
- Status do carro
- Histórico de última corridas

Tecnologias:
- HTML & CSS 
- JavaScript
- React
- NodeJs

 ## 📋 Pré-requisitos

Antes de começar, você precisa ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão 18 ou superior) - **inclui o npm**
- [Git](https://git-scm.com/)
- [VSCode](https://code.visualstudio.com/) (recomendado)

Para verificar se já possui instalado, rode no terminal:
<pre> node -v </pre>
<pre> npm -v </pre>
<pre> git --version </pre>


## 🔧 Instalação e Execução

### 1. Clone o repositório

<pre> https://github.com/Bru-Fasani/Dashboard_React.git </pre>

### 2. Acesse a pasta do projeto
<pre> cd Dashboard_React </pre>
<pre> cd Dashboard </pre>


### 3. Abra no VSCode
<pre> code . </pre>
<pre> Ou abra manualmente: **File → Open Folder → selecione a pasta do projeto** </pre>

### 4. Abra o terminal integrado do VSCode

<pre> Atalho: `Ctrl + '` (Windows/Linux) ou `Cmd + '` (Mac) </pre>

### 5. Instale as dependências
<pre> npm install </pre>


### 6. Execute o projeto
<pre> npm run dev </pre>


### 7. Acesse no navegador

<pre> Abra [http://localhost:5173](http://localhost:5173) (Vite) ou [http://localhost:3000](http://localhost:3000) (CRA) </pre>

## 📜 Scripts Disponíveis

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera a build de produção na pasta `dist` |
| `npm run preview` | Pré-visualiza a build de produção |
| `npm run lint` | Executa o linter |
