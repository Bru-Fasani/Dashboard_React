# Dashboard React 
## simples dashboar para o gerenciamento de uma equipe de arrancada fictícia, a Thunder Motorsport.

Exibir informações como:
- Estatísticas da equipe 
- Número de vitórias 
- Melhor tempo 
- Status do carro
- Histórico de última corridas

Tecnologias:
- HTML & CSS 
- JavaScript
- React
- NodeJs
